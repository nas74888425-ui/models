# Малыш Ктулху — тряпичная кукла (3D)

Процедурная 3D-модель плюшевого «малыша Ктулху» в стиле фетровых/тряпичных кукол,
собранная кодом в Blender (SDF → меш → роспись вершинными цветами → риг → анимации).
Модель полностью соответствует референсу: бирюзовый фетр, розовые пятна-аплакации,
вышитые звёзды, подгузник, крылья-перепонки с крапом, четыре пары щупалец с розовыми кончиками.

## Анимации

| клип | длина | что происходит |
|---|---|---|
| **Idle** | 72 к / 2.4 с | дыхание, лёгкое покачивание, шевеление щупалец |
| **Laugh** | 48 к / 1.6 с | запрокидывание головы, подпрыгивание корпуса, прищур, тряска щупалец |
| **Cry** | 96 к / 3.2 с | опущенная голова, всхлипывания, ладони у морды, дрожь |
| **Angry** | 60 к / 2.0 с | наклон вперёд, «пыхтение», тремор от злости, крылья расправляются |

30 fps. В GLB клипы лежат как именованные glTF-анимации (`Idle`, `Laugh`, `Cry`, `Angry`),
в `.blend` — как Actions + NLA-треки.

## Как посмотреть

**Онлайн:** https://nas74888425-ui.github.io/models/plush-cthulhu/site/

**Локально:** откройте `site/index.html` (нужен интернет — three.js грузится с CDN);
`plush_cthulhu_animated.glb` должен лежать рядом с ним.

**В своём движке:** импортируйте `models/plush_cthulhu_animated.glb` — это обычный glTF 2.0
со скиннингом и вершинными цветами (`COLOR_0`, материал `felt`).
Масштаб: 1 юнит = 100 px референса, рост ≈ 3.9 юнита, origin под дном куклы, +Z вверх.

**Blender:** откройте `models/plush_cthulhu.blend`, анимации — на NLA-дорожках рига `PlushRig`.

## Как это сделано

Вся геометрия — из SDF, без ручного моделирования:

1. `src/sdf_lib.py` — ядро: `smin/smax`, эллипсоиды, капсулы `chain`, 2D-полигоны с вырезами,
   `narrow_volume` + marching cubes, сварка вершин, лапласиан и проецирование на точную SDF-поверхность
   (убирает «складки» и следы децимации).
2. `src/plush/body.py` — анатомия: голова, морда-эллипсоид, глазницы с прямой линией века,
   туловище, руки/ноги-цепочки, 4 пары щупалец.
3. `src/plush/wings.py` — крылья-перепонки: полигон из 13 точек с scallop-вырезами по краю, 4 «пальца».
4. `src/plush/details.py` — глаза (радужка через тороидальные углы, блик, зрачок), подгузник как смещённая
   оболочка от тела с валиком пояса, пупок, крылья.
5. `src/plush/paint.py` — роспись вершинными цветами: фетровый шум, пятна-аплакации (жёсткий край),
   звёзды в цилиндрической развёртке конечностей (как вышивка), розовые кончики щупалец, подушечки лап.
   Все цвета переводятся sRGB → linear перед записью.
6. `src/rig.py` — 57 костей (позвоночник, голова, челюсть, глаза, веки, 24 кости щупалец, конечности, крылья).
   Веса — гауссиана по расстоянию до кости + сглаживание по топологии меша (4 итерации), максимум 3 влияния на вершину (glTF-friendly).
7. `src/anim.py` — клипы через процедурные кривые (синусы/затухания), поддержка Blender 5.x
   (`action.layers[].strips[].channelbags[].fcurves`).
8. `src/build_scene.py` — сборка сцены: веки-полуэллипсоиды, материалы фетра (шероховатость 0.93,
   sheen, двухмасштабный bump-ворс 90/620, волокно через Mix Multiply с вершинным цветом), свет (key/fill/rim), камера, рендер.
9. `src/export_glb.py` — экспорт GLB с `export_animation_mode='NLA_TRACKS'` + сохранение `.blend`.

## Пересборка с нуля

```bash
pip install bpy fast-simplification trimesh scipy numpy pillow   # важен bpy нужной версии
python3 src/build_assets.py          # SDF → models/*.npz  (~1.5 мин, 2 ядра)
python3 src/build_scene.py           # собрать сцену и сохранить .blend (~5 с)
python3 src/build_scene.py render    # hero-рендер Cycles (~2 мин)
python3 src/export_glb.py            # models/plush_cthulhu_animated.glb
```

## Ограничения

- Роспись — вершинные цвета, поэтому мелкая деталь (стежки, крап) видна вблизи, но не является текстурой;
  для texturing-пайплайна геометрию можно запечь в UV-атлас.
- Материал в GLB упрощён до базового PBR с вершинными цветами (сложные шейдеры Blender не переносятся).
- Скиннинг делался автоматически по расстояниям до костей: для крайних поз (очень сильный изгиб)
  возможны лёгкие артефакты, штатные клипы проверены рендером.
